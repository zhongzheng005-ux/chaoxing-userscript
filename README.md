# 功能说明

> ⚠️ 以下能力清单**仅为说明脚本的技术实现范围**，便于审阅与安全评估，**不构成使用授权，也不代表作者鼓励任何具体用途**。使用者的实际使用行为**完全由其自行负责**，与作者无关。

| 模块 | 做什么 |
|---|---|
| **视频 / 音频任务点** | 静音 + 倍速播放；被平台 pause 打断会自动补播 |
| **PPT / PDF / 文档任务点** | 把预览器滚到底，触发平台自身的完成判定 |
| **跳章** | 「下一节」按钮 → 侧栏目录 → 键盘，三条路依次兜底 |
| **章节测验 / 作业** | 识别题目、作答、点选后回读校验、交卷前复核（防白卷） |
| **答题通道** | ① 本地题库 → ② 外部题库 API → ③ AI 大模型（DeepSeek / 智谱 GLM / OpenRouter / SiliconFlow / 本地 Ollama，Key 自己填） |
| **加密字库题干** | 题干的 `font-cxsecret` 反爬字体自动还原成正常汉字 |
| **白屏 / 黑屏自愈** | 跳转后黑屏或空白 → 自动 `load()` 重载、必要时刷一次页面 |
| **后台保活** | 20kHz 音频 + Worker 心跳，切后台不被节流 |

面板分四个标签：**运行日志 / 设置 / 题库 / 诊断**。

> ⚠️ **上述每一项能力都可能违反平台服务条款与学校规章制度。作者列出它们，是为了让你清楚地知道这份代码「能做什么」，从而决定不要用它做那些事。请在阅读完毕后立即删除。**

# 安装

> ⚠️ 安装即表示你已阅读并同意本文件顶部全部条款。**如果你不确定自己是否应当安装，那就不要安装。**

1. 浏览器装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. **Edge / Chrome 新版必须先打开扩展的「允许用户脚本」开关**，否则油猴装了也跑不起来：
   - 打开 `edge://extensions/?id=<篡改猴的扩展ID>`（Chrome 是 `chrome://extensions/`）
   - 找到「允许用户脚本 / Allow user scripts」→ 打开
3. 打开 `chaoxing-autocourse-helper.user.js`（或直接拖进浏览器窗口），油猴会弹出安装页 → 安装。
4. 进入学习通章节学习页，右上角出现面板即成功。
5. **研究完成后请立即卸载**：油猴中删除该脚本 → 删除本地 `.user.js` 文件 → 清理浏览器缓存。

# 使用要点

> ⚠️ 以下说明**仅为让审阅者理解脚本的行为边界**，**不是使用指导**。请在研究后关闭全部开关并尽快删除脚本。

- **默认只做「安全」的事**：不会替你跳过没做完的任务点，也不会替你交没填完的卷子。
- 想让它强行跳过未完成任务点：设置页打开「跳过未完成弹窗」（**会丢进度，慎用**）。
- 答题要用 AI：设置页填自己的 API Key（默认智谱 GLM 免费档），可开「双模型互检」。
- 想让它安静工作：面板里把速度调到 2x、打开静音、勾选「后台保活」。

# 安全：不内置任何 API Key

脚本本身**不含任何密钥、账号、Cookie 或个人信息**。所有 API Key 都只能由你在面板「设置」里自行填写，保存在你自己浏览器的 `localStorage`（`GM_setValue`）中，请求直接从你的浏览器发往你填的服务商，不经过任何中间服务器。

> 但请注意：**「不含密钥」不等于「安全」**。脚本会与页面 DOM 深度交互，**可能**因平台改版而失效、报错，甚至影响页面正常显示。**请仅在你有能力承担这些后果时使用。**
